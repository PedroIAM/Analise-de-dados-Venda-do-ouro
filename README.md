📊 Análise de Preços do Ouro (2015 - 2026)

Este projeto realiza uma análise exploratória dos preços do ouro entre os anos de 2015 a 2026, identificando as maiores e menores variações de preço (High) ao longo do período.

O sistema também gera visualizações gráficas para facilitar a interpretação dos dados.

🚀 Objetivo do Projeto

O objetivo é praticar conceitos de:

Análise de dados com Pandas
Visualização com Matplotlib
Manipulação de dados reais
Filtragem e ordenação de datasets financeiros

Além disso, o projeto simula um cenário básico de análise de mercado financeiro.

📁 Dataset

Ele contém informações históricas sobre o preço do ouro, incluindo:

📅 Data / Ano
💰 Preço de fechamento
📈 Valor High (maior valor do dia/período)
⚙️ Funcionalidades

O sistema permite:

📌 1. Maiores vendas do ouro
Exibe os 5 maiores valores de High
Mostra gráfico comparativo
📌 2. Menores vendas do ouro
Exibe os 5 menores valores de High
Mostra gráfico comparativo
📊 Visualização

O projeto gera gráficos combinados com:

📊 Barras (Bar chart)
📈 Linha (Line plot)
🔵 Pontos (Scatter plot)

🧠 Tecnologias utilizadas
Python 🐍
Pandas 📊
Matplotlib 📈
NumPy 🔢
